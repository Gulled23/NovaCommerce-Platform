# NovaCommerce Platform

## Overview

NovaCommerce Platform is a production-style Platform Engineering project designed to simulate the work performed by modern Cloud, DevOps and Platform Engineers.

The project demonstrates how a cloud-native application can be designed, deployed, secured and operated using modern engineering practices across AWS and Azure.

---

## Objectives

* Build production-ready cloud infrastructure.
* Implement Infrastructure as Code using Terraform.
* Deploy containerised applications with Docker and Kubernetes.
* Build CI/CD pipelines using GitHub Actions.
* Implement monitoring and observability.
* Apply cloud security best practices.
* Produce engineering documentation, runbooks and architecture diagrams.
* Simulate real-world engineering workflows using Jira.
